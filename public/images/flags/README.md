## Recommended Specifications:

- Format: PNG with transparency
- Dimensions: 300x200px or similar 3:2 ratio
- File size: Keep under 50KB per image

## Free Flag Resources:

- https://flagpedia.net/ (download section)
- https://www.countryflags.com/
- Use official government sources when available

## Temporary Placeholder:

Until you add the actual flags, you can use a placeholder service like:
`https://flagcdn.com/w320/{country-code}.png`

Example: `https://flagcdn.com/w320/al.png` for Albania
